# AWS Infrastructure with Terraform

A Terraform project provisioning AWS infrastructure for a cloud portfolio.

## Resources Provisioned
- **VPC** – Custom Virtual Private Cloud with subnets
- **EC2** – Virtual machine instance
- **S3** – Object storage bucket

## How to Use
1. Clone the repo
2. Run `terraform init`
3. Run `terraform plan`
4. Run `terraform apply`

## Prerequisites
- AWS CLI configured
- Terraform installed
